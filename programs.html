Data Analytics

Data Analytics introduces learners to practical data analysis: working with spreadsheets, cleaning messy data, querying with SQL, visualizing findings, and answering business questions with data.

  • FormatPractical, hands-on
  • Length30-day internship
  • FocusData analysis

What you'll explore

Spreadsheet analysis

Organize, sort and summarize data in spreadsheets to start answering questions.

Data cleaning

Find and fix errors, gaps and inconsistencies so data can be trusted.

SQL

Use the standard language of databases to retrieve and filter the data you need.

Data visualization

Turn numbers into charts and visuals that make findings easy to understand.

Business-focused analysis

Connect data to real business questions and explain what the results mean.

Learn by doing

Each area is explored through practical, hands-on tasks.

Skills you can develop

  • Analytical thinking
  • Organizing and summarizing data
  • Cleaning and preparing data
  • Querying data with SQL
  • Visualizing and presenting findings
  • Applying data to business questions

Web Development

Web Development introduces learners to practical website development: structuring pages with HTML, styling them with CSS, adding behavior with JavaScript, tracking work with Git and GitHub, and building web projects.

  • FormatPractical, hands-on
  • Length30-day internship
  • FocusWebsite development

What you'll explore

HTML

Structure the content of a page: headings, text, links, images and forms.

CSS

Style and lay out pages so they look good on any screen size.

JavaScript

Add interactivity so pages respond to what visitors do.

Git/GitHub

Track changes to your code and share your work through GitHub.

Building web projects

Bring the pieces together into complete websites and web projects.

Learn by building

Each area is explored through practical, hands-on tasks.

Skills you can develop

  • Structuring pages with HTML
  • Styling layouts with CSS
  • Adding interactivity with JavaScript
  • Using Git and GitHub
  • Building and presenting web projects
